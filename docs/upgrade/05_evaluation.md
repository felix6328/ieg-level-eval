# Phase 2 · 评测与校准

IEG 在现有 H1–H10 前加类型边界检查，保留旧规则 ID。不适用和无法检查的结果用 `NOT_CHECKED`。每次评测保存规则集、状态、实际值、预期值、证据、严重程度及建议。

REPLAY 读取历史 v3 答题与评分。原文引文重新做连续匹配，缺答案的占位分记录为未调用。Terra 的 40 份标注作为独立模型参照，逐维核验字段与引文。校准界面展示样本数、跨家族一致、维度分差、原文有效性、历史重测以及按任务去重而与校准集隔离的留出子集。每项模型比较都显示分母及来源。REAL 可配置独立 Judge，要求结构化得分、原文和置信度，单列费率估算与失败。

Phase 2 验证 10 项通过，含全部 40 份 Terra 参照的引文校验和异常 Schema 验证。
