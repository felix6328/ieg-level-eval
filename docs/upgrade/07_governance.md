# Phase 4 · Bad Case、Golden Case 与重写

Trace 关联生成收据、解析／Schema、规则、语义证据和分流，返回首次可观察偏离。根因可先保持 Unknown，确认时单独登记审核人和理由。候选从 Bad Case 产生，可修改最小复现需求及断言。验证记录所见基线结果，批准与发布由显式人工操作完成。发布和退役都产生新的冻结版本。

重写从已存模板和原产物创建请求，单输出最多一次。Replay 只能使用归档对应的重写结果，另列原归档反馈与本次复盘理由。比较硬门槛、断言与可用语义证据，保存时间、估算费用差及未验证的理由。

Phase 4 共 13 项测试通过，覆盖归档重写、重复拒绝、Golden 审批门禁和旧数据版本复跑。
