# Phase 1 · 实验与题库

SQLite 运行库默认位于 `data/ieg/workspace.sqlite`。迁移 SQL 放在 `levelgen/ieg/sql/`。24 条历史任务及 216 份生成归档幂等导入。历史样本 0 使用未带后缀的记录，缺少 `sample` 时按 0 恢复关联。新题库从 JSON 或 JSONL 导入，具名数据集的每次写入生成新版本。冻结后可复用，不对版本原位写入。

实验保存模板原文、模板哈希、模型、目标数据集、生成配置、任务和重复号。REPLAY 按组别、历史任务和重复号读取原始归档。历史请求在需要展示时以可用模板重构，种子保留未知。解析失败的原文仍在尝试记录里。REAL 显式启用后才可请求 Provider，完整响应入库，费用按配置估价。重启恢复尚未完成的离线任务；中断的 REAL 请求标为失败，保留远端状态未知的记录。MOCK 用于流程烟测。

Phase 1 验证通过 8 项，覆盖归档、冻结、拒绝不匹配的 Replay 以及保留失败原文和重试记录。
