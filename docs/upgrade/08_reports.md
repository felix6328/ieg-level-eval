# Phase 5 · 模型选型与回归

报告持久化范围和指标分子／分母。同版本、同模式、同任务和样本号的结果才参与结构质量候选比较。报告附模型参照样本数、语义引文、需要复核的比例、人工记录来源、难例表现、费用估算和延迟。真实账单缺失时，每个人工验收输出的实际费用为空。历史三组主表、历史分流、闭环成本和重测单独归档，Replay 费用与历史估价各有来源。

回归以配置组、原任务 ID、重复号及生成需求哈希配对，报告失败与未配对行。对 Golden Case 执行冻结断言，保留两次运行的下钻链接。

Phase 5 共 14 项测试通过。全量 A/B/C Replay 核对 216 次逻辑生成、212 份可解析结果、216 次规则检查和 40 份 Terra 模型参照。
