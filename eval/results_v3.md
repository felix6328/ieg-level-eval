## 3. 生成方差：同一个 spec 生成 3 次，分数有多稳？

ICC(1) = spec 之间的方差 /（spec 之间 + spec 内部）。ICC 低 = 同一个需求每次生成质量差别大，单次采样评估不可靠；「3 次结论一致」= 3 次采样合格与否完全一致的 spec 占比。

| 组 | 四维均分 ICC(1) | 3 次合格结论一致的 spec 占比 | spec 内四维均分平均极差 |
|---|---|---|---|
| A | -0.07 | 50% | 1.13 |
| B | 0.05 | 46% | 0.79 |
| C | 0.63 | 79% | 0.20 |
