# 「评审反馈 → 定向重写」闭环实验

评审 = v3 三家族集成 -cal；每个不合格关卡最多重写 1 次，由**同一个生成模型**完成；复评用同一评审。
每关评审成本（三家合计，实测均值，含重试）≈ ¥0.0110；评审时延按三家并行取最慢 ≈ 15s。
⚠️ 评审校准偏移来自待作者人工复核的临时标注。72B 单价 ¥4.13/M 为配置中的假设价；7B 在 SiliconFlow 为免费档，括号内给出按 ¥0.35/M 付费版的假设成本。
